# Exercícios com loops

Página de exercícios de JavaScript com tema inspirado em Cyberpunk 2077.

## Como usar

Abra `index.html` no navegador. Não é necessário instalar dependências.

Cada exercício tem dois botões: um exibe o desenho na página e o outro no console do navegador. Ao clicar, informe uma altura inteira positiva.

- **Triângulo:** adiciona um `#` por linha, alinhado à direita.
- **Árvore:** gera a estrela, a copa e um caule com altura igual a `Math.floor(altura / 2)`. A última linha do caule compõe a base.

## Arquivos

- `index.html`: estrutura e conteúdo.
- `style.css`: cores, layout centralizado e adaptação para celular.
- `script.js`: loops, validação da entrada e eventos dos botões.

Feito com HTML, CSS e JavaScript.
